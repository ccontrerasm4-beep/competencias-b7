# Ecosistema Educativo Digital

Plataforma web educativa.

## Requisitos
- Node.js 20+

## Instalación y ejecución
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Configurar variables de entorno:
   ```bash
   cp .env.ejemplo .env
   ```
   (o en Windows: `copy .env.ejemplo .env`)
3. Iniciar el servidor:
   ```bash
   npm start
   ```
